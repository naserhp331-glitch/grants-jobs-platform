# منصة المنح والفرص الوظيفية الدولية

## Grants & Jobs International Platform

### المميزات الرئيسية

✅ دعم ثلاث لغات (العربية، الإنجليزية، الفرنسية)
✅ واجهة مستخدم فخمة وموثوقة
✅ نظام بحث وفلترة متقدم
✅ لوحة تحكم متكاملة
✅ نظام تسجيل المستخدمين مع رفع الوثائق
✅ متابعة حالة الطلبات
✅ إشعارات فورية
✅ تحسينات SEO
✅ تصميم مستجيب Responsive

## التثبيت والتشغيل

```bash
npm install
cp .env.local.example .env.local
npm run dev
```

الموقع سيكون متاحاً على: http://localhost:3000

## البنية

- `pages/` - صفحات التطبيق
- `components/` - المكونات القابلة لإعادة الاستخدام
- `lib/` - الدوال المساعدة
- `styles/` - الأنماط
- `public/` - الملفات الثابتة
- `api/` - API الخادم
